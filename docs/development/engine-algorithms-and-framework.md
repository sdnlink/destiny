### 1.2 核心架构原则与设计约束

1. **绝对确定性与零随机依赖（Deterministic & Reproducible）**：
   所有排盘与推演计算均为纯函数（Pure Functions）。相同的输入数据与算法规则版本必产生比特级一致的输出。自动起卦采用基于密码学哈希（HMAC/SHA-256）的可重放凭证机制。
2. **输入快照不可变（Immutable Input Snapshots）**：
   计算请求进入引擎前生成规范化哈希（`canonical_hash`），计算过程严禁反向修改输入入参。
3. **计算内核与 AI 解释层完全解耦**：
   9 大推理计算内核内部严禁调用任何黑盒大型语言模型（LLM）。所有排盘事实、神煞、星宿、体用生克均由严密的数学模型与经典算法给出；AI 服务仅作为可选的外挂文本润色插件。
4. **规则版本化与证据链可追溯（Rule Versioning & Evidence Tracing）**：
   每个计算结果均携带 `engine_version`、`rule_version` 以及完整的 `calculation_trace` 和 `steps`（步骤、操作、输入、输出、引用规则 ID）。
5. **故障隔离与模块自治（Fault Tolerance）**：
   各术数模块间无硬依赖。单一模块计算异常绝不影响其他模块正常排盘。

### 2.2 本卦、变卦、互卦、错卦、综卦派生数学原理

对于任意由 6 个爻位组成的本卦二进制序列 $L = (l_0, l_1, l_2, l_3, l_4, l_5)$（其中 $l_0$ 为初爻，$l_5$ 为上爻）：

1. **本卦（Original Hexagram）**：
   * 下卦（内卦）三爻：$T_{\text{lower}} = (l_0, l_1, l_2)$
   * 上卦（外卦）三爻：$T_{\text{upper}} = (l_3, l_4, l_5)$
   * 卦序：$\text{Ordinal} = \text{Matrix}[T_{\text{upper}}.\text{number}-1][T_{\text{lower}}.\text{number}-1]$

2. **变卦（Changed Hexagram）**：
   * 动爻集合 $M \subseteq \{1, 2, 3, 4, 5, 6\}$
   * 变卦爻序列：$l'_i = \begin{cases} 1 - l_i, & \text{若 } i+1 \in M \\ l_i, & \text{若 } i+1 \notin M \end{cases}$

3. **互卦（Mutual Hexagram）**：
   * 下互卦取本卦的 **二爻、三爻、四爻**：$T_{\text{mutual\_lower}} = (l_1, l_2, l_3)$
   * 上互卦取本卦的 **三爻、四爻、五爻**：$T_{\text{mutual\_upper}} = (l_2, l_3, l_4)$
   * 互卦六爻序列：$L_{\text{mutual}} = (l_1, l_2, l_3, l_2, l_3, l_4)$

4. **错卦（Opposite / Complementary Hexagram）**：
   * 六爻全部阴阳对转（阳变阴，阴变阳）：
   * 错卦六爻序列：$L_{\text{opposite}} = (1-l_0, 1-l_1, 1-l_2, 1-l_3, 1-l_4, 1-l_5)$

5. **综卦（Reversed / Inverted Hexagram）**：
   * 卦体上下颠倒 180°（初爻变上爻，二爻变五爻……）：
   * 综卦六爻序列：$L_{\text{reversed}} = (l_5, l_4, l_3, l_2, l_1, l_0)$

### 2.3 易学同构特殊卦象深度解析

根据上述数学模型，64 卦在几何与阴阳对称性上呈现出确凿的同构特征：

* **互卦 = 错卦 = 综卦（三者完全同一卦）**：
  * **第 63 卦《水火既济》**（`1, 0, 1, 0, 1, 0`）的所有派生卦（互、错、综）在数学上完全等同于 **第 64 卦《火水未济》**（`0, 1, 0, 1, 0, 1`）。
  * **第 64 卦《火水未济》**（`0, 1, 0, 1, 0, 1`）的所有派生卦在数学上完全等同于 **第 63 卦《水火既济》**。
* **错卦 = 综卦（错综同体，共 6 卦）**：
  * 《泰》与《否》、《随》与《蛊》、《渐》与《归妹》。
* **综卦为自身（正卦/反易不倒卦，共 8 卦）**：
  * 《乾》、《坤》、《颐》、《大过》、《坎》、《离》、《中孚》、《小过》。
* **互卦为自身（纯阳/纯阴，共 2 卦）**：
  * 《乾》、《坤》。

## 3. 9 大推理计算引擎与算法全景详解

### 3.1 历法与天文演算内核（Calendar Engine）
* **源码目录**：`app/calendar/`
* **计算方法与数学模型**：
  1. **定气法节气计算**：基于 VSOP87 天文摄动模型与太阳视黄经 $\lambda_{\odot}$，精确计算 24 节气达到 $k \times 15^\circ$ 的分钟级 UTC 时刻。
  2. **真太阳时校正**：
     $$T_{\text{true}} = T_{\text{local}} + 4 \times (\text{Longitude} - 120^\circ) + EOT(t)$$
     其中 $EOT(t)$ 为均时差方程（Equation of Time），消除地球椭圆轨道与黄赤交角引起的日长周期性变化。
  3. **四柱干支推导算法**：
     * **年柱**：以立春（Solar Term 1）时刻为年界线。
     * **月柱**：以十二节令（立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒）换月，年上起月采用“五虎遁”。
     * **日柱**：基准儒略日（Julian Day Number）模 60。
     * **时柱**：日上起时采用“五鼠遁”。23:00~24:00 为夜子时（属于当日干），00:00~01:00 为早子时（属于次日干）。

### 3.2 周易象数推演内核（Zhouyi Engine）
* **源码目录**：`app/zhouyi/`
* **支持方法**：
  1. **手工六爻法 (`manual`)**：接收 6 个爻值（$6=$ 老阴动，$7=$ 少阳静，$8=$ 少阴静，$9=$ 老阳动），生成本卦并翻转 $6/9$ 得变卦。
  2. **双数法 (`numbers`)**：
     $$\text{Lower} = (N_1 \pmod 8) \text{ 或 } 8, \quad \text{Upper} = (N_2 \pmod 8) \text{ 或 } 8, \quad \text{Moving} = ((N_1 + N_2) \pmod 6) \text{ 或 } 6$$
  3. **版本化三数法 (`three_numbers`)**：
     * 第一数 $N_1$ 映射上卦，第二数 $N_2$ 映射下卦，第三数 $N_3 \pmod 6$（余 0 归 6）独立取动爻（第三数不与前两数求和）。
  4. **时间起卦法 (`time`)**：
     $$\text{Upper} = (Y_{\text{branch}} + M_{\text{lunar}} + D_{\text{lunar}}) \pmod 8$$
     $$\text{Lower} = (\text{Upper} + H_{\text{branch}}) \pmod 8, \quad \text{Moving} = (\text{Upper} + H_{\text{branch}}) \pmod 6$$

### 3.3 梅花易数推演内核（Meihua Engine）
* **源码目录**：`app/meihua/`
* **计算方法与体用判定算法**：
  1. **起卦模型**：支持两数、三数、农历时间及物数字数起卦。
  2. **体用卦严格定位**：
     * 若动爻在 1、2、3 爻（下卦），则 **下卦为用卦，上卦为体卦**。
     * 若动爻在 4、5、6 爻（上卦），则 **上卦为用卦，下卦为体卦**。
  3. **五行生克关系状态机**：
     * 体用比和（同五行）：最吉，互助共赢。
     * 用生体：大吉，外来助益。
     * 体生用：耗泄，损己利人。
     * 用克体：大凶，外力制约阻碍。
     * 体克用：小吉，劳而有获。
  4. **时态推演**：本卦体用定初始现状，互卦体用定中途演变，变卦体用定最终结局。

  2. **纳甲天干地支装配（京房纳甲诀）**：
     * 乾内甲子寅辰，外壬午申戌；坤内乙未巳卯，外癸丑亥酉；

     * 坎内戊寅辰午，外戊申戌子；离内己卯丑亥，外己酉未巳；
     * 艮内丙辰午申，外丙戌子寅；兑内丁巳卯丑，外丁亥酉未。

  5. **本宫伏神提取**：当本卦六亲不全时，自动索引本宫纯卦相应爻位提取伏神。

### 3.5 八字命理排盘内核（Bazi Engine）
* **源码目录**：`app/bazi/`

     * 计算出生时刻至下一个节令（顺行）或上一个节令（逆行）的折算起运年龄（3天折合1年，1天折合4个月，1个时辰折合10天）。
  4. **十二长生状态机**：长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养状态映射。

### 3.6 紫微斗数排盘内核（Ziwei Engine）
* **源码目录**：`app/ziwei/`
* **计算方法与安星推导模型**：
  1. **命宫与身宫定位**：
     * 从寅宫起正月，顺数至生月；再从该宫起子时，**逆数至生时安命宫**，**顺数至生时安身宫**。
  2. **五行局判定**：
     * 由命宫所在干支，根据六十甲子纳音五行定出水二局、木三局、金四局、土五局、火六局。
  3. **紫微星与天府星定位算法**：
     * 紫微星落宫公式：依据五行局数 $B$ 与农历出生日数 $D$ 查安星数理或应用商余定位。
     * 天府星位置与紫微星在寅申线上对称：$\text{Tianfu} = (4 - \text{Ziwei}) \pmod{12}$。
  4. **诸星排布**：
     * 紫微星系（逆布）：紫微 $\rightarrow$ 天机 $\rightarrow$ (空一格) $\rightarrow$ 太阳 $\rightarrow$ 武曲 $\rightarrow$ 天同 $\rightarrow$ (空两格) $\rightarrow$ 廉贞。
     * 天府星系（顺布）：天府 $\rightarrow$ 太阴 $\rightarrow$ 贪狼 $\rightarrow$ 巨门 $\rightarrow$ 天相 $\rightarrow$ 天梁 $\rightarrow$ 七杀 $\rightarrow$ (空三格) $\rightarrow$ 破军。
  5. **生年干四化星**：甲廉破武阳、乙机梁紫阴、丙同机昌廉、丁阴同机巨、戊贪月弼机、己武贪梁曲、庚阳武阴同、辛巨阳曲昌、壬梁紫府武、癸破巨阴贪。

### 3.7 奇门遁甲推演内核（Qimen Engine）
* **源码目录**：`app/qimen/`
* **计算方法与九宫布盘模型**：
  1. **阴阳遁与局数推演（拆补法）**：
     * 冬至后至夏至前为 **阳遁**（顺布六仪，逆布三奇）；夏至后至冬至前为 **阴遁**（逆布六仪，顺布三奇）。
     * 依据日干支符头（甲子、甲戌、甲申、甲午、甲辰、甲寅）与节气定出上元、中元、下元及 1~9 局数。
  2. **地盘三奇六仪排布**：戊、己、庚、辛、壬、癸、丁、丙、乙落洛书九宫。
  3. **值符（九星之首）与值使（八门之首）定位**：
     * 依据时辰干支旬首确定值符星与值使门地盘落宫。
  4. **天盘旋转、人盘八门运转与神盘排布**：
     * 天盘九星（蓬、芮、冲、辅、禽、心、柱、任、英）随时干落宫运转。
     * 人盘八门（休、生、伤、杜、景、死、惊、开）随时支落宫飞布。
     * 八神盘（值符、腾蛇、太阴、六合、白虎、玄武、九地、九天）随天盘值符旋转。

### 3.8 大六壬神课推演内核（Daliuren Engine）
* **源码目录**：`app/daliuren/`
* **计算方法与九宗门发传模型**：
  1. **天地盘排布**：月将加于占时地支之上，顺时针推布十二地盘天盘。
  2. **四课建立**：
     * 第一课（日阳）：日干上神加日干。
     * 第二课（日阴）：第一课上神加于日干之上神。
     * 第三课（辰阳）：日支上神加日支。
     * 第四课（辰阴）：第三课上神加于日支之上神。
  3. **九宗门三传完整判定算法**：
     * **贼克法**：首取下贼上，次取上克下。
     * **比用法**：克位有二三者，取与日干阴阳相比（阳日用阳，阴日用阴）发传。
     * **涉害法**：比用仍俱比或俱不比，取涉归本位受克深者发传。
     * **遥克法**：四课全无克贼，取神遥克日干（蒿矢）或日干遥克神（弹射）。
     * **昴星法**：四课无克无遥，阳日取酉上神，阴日取日干上神发传。
     * **别责法**：四课不全又无克，阳日取干合上神，阴日取支前三合发传。
     * **八专法**：干支同位无克贼，阳日顺行三位，阴日逆行三位发传。
     * **伏吟法**：天地盘重合，阳日取日干上神，阴日取日支上神发传。
     * **返吟法**：天地盘对冲，取驿马或支上神发传。
  4. **贵人与十二天将排布**：依据日干分昼夜贵人，顺行或逆行排布贵人、螣蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后。

### 3.9 阳宅风水方位与玄空内核（Fengshui Engine）
* **源码目录**：`app/fengshui/`
* **计算方法与空间几何模型**：
  1. **二十四山罗盘度数精确映射**：
     * $360^\circ$ 圆周划分为 24 山，每山精确占 $15^\circ$（正中为下卦，左右各 $1.5^\circ$ 为兼向，边缘界线触发大空亡、小空亡预警）。
  2. **真北与磁偏角修正**：支持输入当地磁偏角 $\Delta \theta$，自动将磁北读数修正为真北坐向。
  3. **多次测量共识算法**：
     * 基于单位向量平均法计算角度圆周均值：
       $$\bar{\theta} = \text{atan2}\left(\sum \sin \theta_i, \sum \cos \theta_i\right)$$
     * 计算最小覆盖弧与保守误差包络，自动判定分类稳定性（`classification_stable`）。
  4. **八宅明镜游年八星推导**：
     * 依据坐山卦判定东四宅（震、巽、离、坎）与西四宅（乾、坤、艮、兑）。
     * 依据大门方位推布生气、延年、天医、伏位（四吉方）与绝命、五鬼、六煞、祸害（四凶方）。
  5. **玄空飞星三元九运模型**：
     * 输入当令运数（如八运、九运），飞布运盘中宫。
     * 依据坐向山向飞布山盘与向盘（依阴阳顺飞或逆飞），分析旺山旺向、双星会向、上山下水等局势。

## 4. 综合研判、类象分析与文献语料层

### 4.1 多术数综合研判（Cross-System Synthesis）
* **源码位置**：`app/core/synthesis.py`
* **功能**：当用户同时执行多个术数排盘时，系统自动对齐各模块事实（卦象五行、体用生克、八字喜用、奇门吉凶星门），对判断结论进行 `consistent`（高度一致）、`complementary`（互补印证）、`conflicting`（冲突分歧）及 `indeterminate`（无法判定）的结构化分类。

### 4.2 事项分类检查清单与建议（Advisory System）
* **源码位置**：`app/core/advisory.py`
* **功能**：针对用户指定的 8 大现实事项维度（事业求职、商业财富、情感婚姻、健康调理、学业考试、置业搬迁、诉讼纠纷、出行迁徙），结合盘面五行旺衰生成可操作的逻辑推演检查清单与风险防范建议。

### 4.3 经典文献语料检索与考证（Corpus & Literature）
* **源码位置**：`app/core/literature.py` 与 `app/corpus_api.py`
* **功能**：基于 ClickHouse 存储的经典古籍语料（《周易正义》、《梅花易数》、《卜筮正宗》、《增删卜易》、《渊海子平》、《三命通会》、《滴天髓》、《紫微斗数全书》、《奇门遁甲统宗》、《大六壬指南》），提供与当前卦象、格局精确绑定的原文对勘与章节索引。

### 4.4 万物类象映射矩阵（Imagery Dimensions）
* **源码位置**：`app/core/imagery.py` 与 `app/main.py`
* **功能**：提供八卦与干支在天时、地理、人物、脏腑、器物、动物、颜色、场所等 12 个维度的完整类象字典，供推演解释层直接引用。
