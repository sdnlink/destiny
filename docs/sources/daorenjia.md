# 道人家来源评估

> 来源：<https://www.daorenjia.com/>  
> 核查日期：2026-08-15  
> 当前执行范围：按用户指定，仅缓存书籍正文纯文本；不下载图片和附件，不对外再发布

## 1. 来源用途

道人家提供道藏目录、分类、在线文本、校对状态、图片和下载入口。项目可以利用该网站发现相关书目、定位参考文本和辅助人工校勘。

该来源不能被直接视为术数规则的唯一权威来源。正式规则仍需要引用可定位的具体经典版本、篇章和段落，并经过领域专家审核。

## 2. 自动访问核查

核查时，`https://www.daorenjia.com/robots.txt` 内容为：

```text
User-agent: *
Disallow: /build/
Disallow: /piwik/
Disallow: /web/
```

这表示通用自动客户端不应访问上述路径。它不代表网站授予复制、缓存、改编、再发布或商业使用内容的权利。

网站没有在首页和“关于本站”页面提供明确的开放许可证或批量缓存条款。

## 3. 权利风险

网站“关于本站”说明：

- 源文件来自其他网站提供的DJVU文件。
- 大部分现成文本来自其他在线网站。
- 校对工作参考《中华道藏》DJVU版。
- 页面图片主要来自《中华道藏》电子版。

因此需要分别考虑：

- 古代经典原始文本可能属于公版内容。
- 现代选编、排版、校订、标点和注释可能存在独立权益。
- 《中华道藏》的现代汇编、电子版和页面图片不能仅因原始经典年代久远就视为可自由复制。
- 网站是否有权向第三方授予再利用许可仍需确认。

## 4. 当前执行范围

根据项目当前要求，仅执行以下操作：

- 保存网站名称、首页URL和访问日期。
- 保存书名、目录分类、页面URL和校对状态等必要书目元数据。
- 保存用于更新检测的页面时间、响应头或内容校验值，不保存可还原全文的内容。
- 由研究人员人工打开页面进行检索和交叉校勘。
- 在内部来源记录中保存准确链接，不向终端用户冒充自有内容。
- 以低频、单线程方式缓存书籍页面 `content4` 区域中的正文纯文本，供项目内部研究和数据盘点。
- 为每本书保存来源URL、抓取时间、字符数和SHA-256校验值。

## 5. 当前禁止范围

- 批量镜像全站。
- 将缓存正文对外再发布、公开下载或提供未经审核的全文检索。
- 下载、缓存或展示页面图片和DJVU/PDF文件。
- 绕过访问控制、验证码、限流或被禁止路径。
- 将该网站内容用于模型训练或商业知识库全文检索。
- 删除来源标识，或将网站校订成果标记为项目原创。

## 6. 获得授权后的要求

书面授权至少需要明确：

| 项目 | 必须确认的内容 |
| --- | --- |
| 授权主体 | 是否拥有相关文本、校订和图片的授权能力 |
| 内容范围 | 具体栏目、书目、文本、图片或下载文件 |
| 使用方式 | 缓存、结构化、搜索、展示、API、商业使用 |
| 使用期限 | 起止时间和续期方式 |
| 地域与产品 | 可使用地区及具体产品范围 |
| 署名要求 | 网站名、作者、链接和展示位置 |
| 内容更新 | 更新频率、增量获取和删除同步 |
| 撤回机制 | 权利异议、下架请求和完成期限 |
| 上游权利 | 第三方文本、电子书和图片是否包含在授权中 |

授权文件应进入受控文档库，保存版本和SHA-256校验值，并在 `data_sources` 中更新许可状态。

## 7. 后续技术方案

获得授权后再设计采集器，并遵守以下原则：

- 使用可识别的User-Agent和项目联系信息。
- 严格遵守 `robots.txt` 及站方提供的访问频率。
- 优先使用站方提供的数据包或接口，不抓取展示页面。
- 支持限速、断点续传、增量更新和内容删除同步。
- 原始响应、解析文本和生产发布内容分层存储。
- 每条内容保存来源URL、获取时间、校验值、许可版本和解析器版本。
- 采集失败不进行高频重试，不影响对方网站稳定性。
