# ADR-012：大六壬独立领域第六阶段基线

> 状态：第六阶段工程实现完成，全部术数规则待专家签署
> 日期：2026-08-16

## 1. 目标与边界

大六壬必须是独立领域，不借用周易卦象、梅花体用或六爻动爻算法。本阶段将实现迁入`app/daliuren`，只依赖统一历法和`app/common`中的干支、五行及确定性凭证工具。`app/core/liuren.py`只保留历史导入兼容。

内核不调用语言模型、语料检索或随机源。每个结果保留输入、归一化时间、月将、占时、天地盘、四课、发传检测、十二天将、旬空、完整计算轨迹和规则版本。

## 2. 输入语义

### 2.1 时间排盘

时间入口从统一历法读取日干支和实际时支，以实际时支为占时。月将按最近中气确定，再将月将加临占时顺布十二天盘。

### 2.2 数字占时

数字入口只接受严格整数。整数映射到子至亥十二占时，余0归亥；数字只改变占时，不修改历法日柱或实际时支。它不是周易式数字起卦。

### 2.3 个体自动入口

个体自动入口使用六壬专属`liuren-report-number-v1`域从凭证派生1至12报数。相同凭证可复算，结果只返回凭证哈希；实际时支继续保留。

## 3. 天地盘、四课和天将

- 月将加临占时后，十二支按固定顺序形成天盘；地盘保持子至亥。
- 四课按十干寄宫取干上神、干阴神、支上神和支阴神。
- 每课记录上下神、五行、阴阳和上下克关系。
- 十二天将按占日天干和昼夜贵人起例定位，并记录顺布或逆布。
- 昼夜当前按当地民用小时6至18时划分，仍是待签署工程基线。

## 4. 发传顺序

发传检测必须按明确次序执行，不能由自然语言推断：

1. 检查下克上贼克；无贼克再检查上克下克法。
2. 多个候选先按日干阴阳执行比用；仍不唯一进入涉害。
3. 天地盘同位进入伏吟，按有克、自任、自信和杜传的刑冲规则发传。
4. 天地盘相冲有克仍按基础克法，无克按井栏射发传。
5. 非伏吟返吟且两课无克时进入八专，按阳顺阴逆三位发传。
6. 检查遥克，先神遥克日为蒿矢，无则日遥克神为弹射；多个候选再比用，比用后仍不定则转入涉害取深（见机/察微/缀瑕），不再返回待选状态。
7. 无遥克时，三课结构进入别责，四课俱全进入昴星。
8. 初传确定后，通常以初传上神为中传、中传上神为末传；涉害、昴星、别责、八专、伏吟和返吟按各自规则确定。

## 6. 资料与版本

所有发传工程规则依据本地开放许可《六壬大全》起例和课例建立。基础起例位于`00000`；涉害位于`00174`至`00176`，别责位于`00180`至`00181`，八专位于`00181`至`00182`，伏吟位于`00182`至`00185`，返吟位于`00185`至`00187`。规则编号分别为`LR-SHEHAI-001`、`LR-BIEZE-001`、`LR-BAZHUAN-001`、`LR-FUYIN-001`和`LR-FANYIN-001`。这些规则仍是草稿，正式发布前要求两名领域专家审核原文、算法和正反案例。

## 7. 测试基线

自动测试覆盖：

- 输入模型不可变，数字拒绝布尔、浮点和字符串；
- 天盘必须是十二地支的完整排列；
- 月将配置和覆盖矩阵不可变；
- 既有克法案例继续得到午、辰、寅；
- 遥克蒿矢案例得到酉、未、巳；
- 遥克比用后仍有多候选时按涉害取深，结果标注`remote_control`与来源路径；
- 阴日昴星案例得到子、辰、戌；
- 涉害原例复现亥、酉、未，并保留每个候选沿途克位；
- 别责覆盖刚日干合和柔日支前三合；
- 八专覆盖阳日顺数与阴日逆数；
- 伏吟覆盖有克、自任、自信、刑序、自刑和杜传取冲；
- 返吟覆盖丁己辛丑未六个无克日井栏射；
- 六十日柱与十二天地盘偏移共720种组合全部得到确定三传；
- 个体自动报数可重放且不泄露原始凭证；
- 大六壬领域不导入周易、梅花、六爻或旧`core`算法。

下一步是组织双专家逐条复核十类发传规则与案例；任何修订使用新的规则版本。工程开发可继续进入阳宅风水独立领域和用户案例持久化，但不得把未签署的大六壬结果标记为正式断案。
