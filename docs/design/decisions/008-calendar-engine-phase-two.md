# ADR-008：统一历法引擎第二阶段基线

> 状态：第二阶段已实现，历法口径待专家与独立数据源复核
> 日期：2026-08-16

## 1. 范围

本阶段只建立统一中国历法领域引擎，提供：

- 公历本地时间、IANA时区和UTC标准化。
- 农历日期、闰月和春节边界。
- 年、月、日、时四柱及结构化天干地支。
- 二十四节气秒级参考时刻及月令节气边界。
- 月建、生肖、时支、旬、旬空和遁干。
- 可选真太阳时修正及完整计算轨迹。

本阶段不修改周易、梅花、六爻或大六壬自身规则。各体系只消费历法输出。

## 3. 时间口径

### 3.1 输入

输入必须是无UTC偏移的本地ISO-8601时间，并单独提供IANA时区。夏令时缺失时间和歧义时间直接拒绝，不猜测用户意图。支持年份范围为1900至2100。

### 3.2 节气

节气不是按15天估算。当前工程基线固定使用`lunar-python 1.4.8`内置寿星节气表，参考时区为`Asia/Shanghai`。引擎先把有效输入时刻转换成同一东八区参考时刻，再判断节气边界，并把节气时刻转换回用户时区和UTC。

输出精度为秒只表示序列化粒度，不表示已经完成独立天文误差评估。正式发布前必须使用另一个可信历书或天文算法交叉验证。

### 3.3 四柱

- 年柱：以立春绝对时刻换年。
- 月柱：以十二个节令绝对时刻换月，寅月立春起、卯月惊蛰起，依次类推。
- 日柱：按有效当地时间计算，当前工程基线在23:00换日。
- 时柱：按有效当地时间的双小时地支计算。

年柱、月柱使用节气参考时刻；日柱、时柱使用用户有效当地时间。该拆分避免把北京时间节气钟表值直接套到其他时区。

### 3.4 农历、月建和生肖

农历日期按东八区参考时刻转换，闰月以正数月份加`is_leap_month`表示。月建直接取月柱地支。生肖按年柱地支并以立春为边界，不以春节为边界；响应明确记录该口径。

### 3.5 真太阳时

真太阳时默认关闭。启用时必须提供经度，记录标准经线、经度时差、NOAA风格均时差近似值、夏令时修正和修正后当地时间。该近似公式不冒充高精度天文历算。

## 4. 输出契约

统一输出包含：

```json
{
  "engine_version": "calendar-engine-2.0.0+lunar-python-1.4.8",
  "rule_version": "calendar-domain-baseline-2.0.0",
  "input": {},
  "normalized_input": {},
  "solar": {},
  "lunar": {},
  "pillars": {},
  "ganzhi": {},
  "solar_terms": {},
  "month_branch": {},
  "zodiac": {},
  "xun": {},
  "xun_kong": [],
  "calculation_trace": [],
  "steps": []
}
```

`steps`保留输入、输出、顺序和规则编号。历法内核不访问LLM、语料库或随机源。
