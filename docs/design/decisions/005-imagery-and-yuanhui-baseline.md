# ADR-005：类象与元会运世工程基线

> 状态：工程采用，内容待专家签署  
> 日期：2026-08-16

## 背景

推演结果不能只展示卦名和盘面，还需要说明卦、爻、六亲、地支和天将在用户所问事项中可能对应的对象、人物、环境与行为。同时，用户要求结合元会运世观察宏观时间位置。这两类内容都存在流派差异，必须与确定性排盘和正式判断分层。

## 类象层

### 数据范围

首版登记八卦的自然、方位、人物、家庭、身体、动物、事物、场所和行为类象；登记十二地支的五行、时令、方位与基本意象；六爻结果同时汇总六亲、世应和动爻，大六壬结果关联月将、三传和天将名称。

### 事项筛选

问题全文不参与排盘公式。用户选择的事项分类只决定优先展示哪些类象维度：

| 事项 | 优先类象维度 |
| --- | --- |
| 事业 | 人物、行为、场所、事物 |
| 财务 | 事物、场所、行为、方位 |
| 关系 | 人物、家庭、行为、身体 |
| 出行 | 方位、场所、自然、行为 |
| 学业 | 人物、事物、行为、场所 |
| 其他 | 自然、人物、事物、场所 |

筛选只改变展示顺序，不删除原始类象，也不把某个象强制等同于现实中的特定人或事件。

### 输出边界

- 输出状态为 `unreviewed_imagery_candidates`。
- 每条候选保留模块、盘面角色、卦或地支、类象维度和规则编号。
- 不自动写入 `judgements`，不产生吉凶、应期和现实概率。
- 书籍检索片段可以作为校核候选，但不能自动修改结构化类象表。

## 元会运世层

### 周期单位

首版采用邵雍象数体系常见工程换算：

- 1元 = 12会 = 129,600年。
- 1会 = 30运 = 10,800年。
- 1运 = 12世 = 360年。
- 1世 = 30年。

### 纪元基线

为保证程序可复算，暂以公元前67,017年作为当前元的起点，对应天文年 `-67016`。公元纪年转换使用无公元0年的显示规则。该纪元选择尚未经过专家和版本案例签署，必须在结果中返回 `epoch_status: pending_expert_review`，后续其他纪元以新规则版本并行增加，不覆盖历史结果。

对公元2026年的工程结果为：第一元、第七会（午会）、第十二运、第十世、世内第十三年。周期按公历年粒度计算，不宣称精确到月日时。

### 与盘面关系

当前会支提供宏观五行背景。系统只比较会支五行与本卦上下卦、梅花体用、六爻卦宫等盘面五行，输出同类、生、克关系事实。关系只说明模型内部结构，不直接表示顺逆、成败或个人命运。

### 来源与校核

- 开放语料：《皇極經世》，Wikisource文档哈希 `04a151f5a0ee3b4a10eca6053a39a089455e0159e6841f8af2caf6b3c98c7437`。
- 内部语料：道人家《皇极经世》缓存版本。
- 结构化单位和纪元仍需专家定位具体卷、版本原文并建立跨边界标准案例。

## 接口与展示

综合计算结果增加：

- `imagery`：类象候选、事项筛选维度、盘面来源和限制。
- `yuan_hui_yun_shi`：周期位置、边界、会支五行和盘面关系证据。

前端在“结论建议”中独立展示这两个事实层，不把它们混入正式综合评分。计算步骤和规则目录必须可见。
