## 文档优先级

发生冲突时，按以下顺序处理：

1. 已签署的决策记录和范围变更记录。
2. 详细项目计划。
3. 本目录中的专项设计。
4. 项目摘要和早期技术验证文档。

任何设计变化如果影响MVP范围、术数规则、隐私策略、验收标准或里程碑，必须先更新详细项目计划，再更新专项设计。

## 状态定义

- 草稿：内容不完整，不能作为开发依据。
- 评审稿：内容已完整，可组织产品、技术和专家评审。
- 已批准：负责人已签署，可作为开发和验收依据。
- 已废止：被新版本替代，仅用于历史追溯。

当前所有设计文档均未批准，不代表正式开发授权。
